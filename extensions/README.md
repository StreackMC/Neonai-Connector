# Extensions for Neonaic
本文件夹用于存放 Neonaic 的拓展。拓展可以为 Neonaic 带来更多的功能，但也请注意恶意拓展！！

加载的拓展拥有访问大部分资源的权限，包括你的 apikey 等敏感数据，请谨慎加载。

## 官方插件
秉承着「解耦合」的概念，我们将边缘功能做成官方插件，默认启用。你可以按需禁用而不造成影响。

参见：[Github 上的此文件](https://github.com/StreackMC/Neonai-Connector/blob/main/extensions/README.md)
