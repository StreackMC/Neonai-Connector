## QQBot intents 范围澄清（群聊 / 好友私信）

- SDK `qq-official-bot` 的 `Intends` 枚举中，「群聊」仅 `GROUP_AT_MESSAGE_CREATE`、「好友/单聊私信」仅 `C2C_MESSAGE_CREATE` 两个有效键（值同为 33554432）。
- 不存在「全部群消息」「好友列表事件」类 intent；QQ 只对机器人推送 @消息 与 C2C 私信。
- **关键区分**：`GUILD_*` 系列（GUILDS/GUILD_MEMBERS/GUILD_MESSAGES...）属「频道(channel)」体系，非「群聊」；`DIRECT_MESSAGE`(4096) 是「频道私信」，非「好友私信」。勿因名字相近误加（上次 GROUP_MEMBER/GROUP_AND_C2C_EVENT 即因此被 SDK 跳过）。
- qqbot.js intents 已显式分组标注群聊 + 好友私信两段，验证位掩码 234881024 含两个消息 bit，无无效键。
- 新增顶部 `INTENTS` 枚举（group/chat/qchannel/common 四类，JSDoc 标注含义）；`bot_conf.intents` 改为引用 `INTENTS.*`。common 类为补充（放 MESSAGE_AUDIT/INTERACTION，原 3 类装不下）。

## enums.js 新增 EVENTS 枚举（bot.on 事件名）

- `src/platform/qqbot/enums.js` 已存在并含 `INTENTS`（业务分类 group/chat/qchannel/common）。本次新增 `EVENTS` 枚举（按 SDK post_type 分 message/notice/session 三类，含 root 全量捕获名）。
- message.* 对应 GROUP_AT_MESSAGE_CREATE / C2C_MESSAGE_CREATE / MESSAGE_AUDIT 等；notice.* 含频道/子频道/好友/群/论坛/按钮 action 事件；session.* 为连接生命周期事件（READY/ERROR/CLOSED/DEAD/EVENT_WS）。
- ⚠️ session 生命周期事件 emit 在 `bot.sessionManager` 上，不在 `bot` 上（`bot.on('READY')` 无效，须 `bot.sessionManager.on('READY')`）。
- node 校验：52 条事件名均为 SDK 真实 emit 名（对照 event/index.js 的 QQEvent + notice.*.action + SessionEvents）。
- 遗留：qqbot.js 内联的 INTENTS 与 enums.js 的 INTENTS 目前重复，后续可统一改为从 enums.js 导入。
