## QQBot intents 范围澄清（群聊 / 好友私信）

- SDK `qq-official-bot` 的 `Intends` 枚举中，「群聊」仅 `GROUP_AT_MESSAGE_CREATE`、「好友/单聊私信」仅 `C2C_MESSAGE_CREATE` 两个有效键（值同为 33554432）。
- 不存在「全部群消息」「好友列表事件」类 intent；QQ 只对机器人推送 @消息 与 C2C 私信。
- **关键区分**：`GUILD_*` 系列（GUILDS/GUILD_MEMBERS/GUILD_MESSAGES...）属「频道(channel)」体系，非「群聊」；`DIRECT_MESSAGE`(4096) 是「频道私信」，非「好友私信」。勿因名字相近误加（上次 GROUP_MEMBER/GROUP_AND_C2C_EVENT 即因此被 SDK 跳过）。
- qqbot.js intents 已显式分组标注群聊 + 好友私信两段，验证位掩码 234881024 含两个消息 bit，无无效键。
- 新增顶部 `INTENTS` 枚举（group/chat/qchannel/common 四类，JSDoc 标注含义）；`bot_conf.intents` 改为引用 `INTENTS.*`。common 类为补充（放 MESSAGE_AUDIT/INTERACTION，原 3 类装不下）。
