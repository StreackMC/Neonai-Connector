## 全量重构 src 模块导出为命名空间对象

- 需求：`src/` 下各模块不再分散具名导出，改为单个命名空间对象，如 `export const NeonaicCommandServer = {}`。例外：`Logger.js` 的 `parseString`。
- 命名规则（与用户确认）：`Neonaic` + 文件名 PascalCase。文件名与类名同名的（`NeonaicConfig.js` → `class NeonaicConfig`、`NeonaicNewableClass.js` → `class NeonaicNewable`）模块对象加 `Module` 后缀，类名保持不变，即 `NeonaicConfigModule`、`NeonaicNewableModule`。
- 另一个必要例外：`log4js_inject.js` 的 `configure`——log4js 把该模块当 appender 加载并要求顶层具名导出，故保留独立导出，只把 `putEmit` 收进 `NeonaicLog4jsInject`。
- 17 个模块的对象名：NeonaicCommandInterface / NeonaicCommandServer / NeonaicPermissionServer / NeonaicExtLoader / NeonaicLogger / NeonaicLog4jsInject / NeonaicAI / NeonaicMessageIn / NeonaicPlatformInterface / NeonaicPlatformManager / NeonaicPlatformUtils / NeonaicConfigModule / NeonaicNewableModule / NeonaicCliProcessor / NeonaicConfManager / NeonaicEntry / NeonaicPidManager。
- 调用点全部收敛为命名空间访问（`NeonaicLogger.getLogger()`、`NeonaicCommandInterface.COMMAND_ENUMS.X`）；类继承写作 `extends NeonaicNewableModule.NeonaicNewable`。
- `src/extension/extMgr.js` 是 0 字节空文件，未处理。
