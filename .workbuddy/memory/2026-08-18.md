# 2026-08-18

## 修复权限持久化转义缺陷

- 文件：`src/handler/permissionServer.js` 的 `_save()`。
- 问题：原用 `JSON5.stringify` 落盘，它不具备 well-formed 序列化能力，会把孤立代理项（U+D800–U+DFFF）原样写出，经 `writeFileSync(..., 'utf8')` 时被替换为 U+FFFD（�），造成静默数据损坏。
- 修复：改用 `JSON.stringify(out, null, 2)`，再 `.replace(/\u2028/g,'\\u2028').replace(/\u2029/g,'\\u2029')` 显式转义行/段分隔符（避免读取端 JSON5.parse 告警）。
- 读取端仍保留 `JSON5.parse`（JSON 超集），兼容旧的 JSON5 格式文件。
- 验证：引号/反斜杠/控制字符/U+2028/U+2029/中文/emoji/孤立代理项/`__proto__` 等全部往返正确。
- 备注：`setPermission` 用普通对象 `map[permission]=...`，若权限名恰为 `__proto__` 会静默丢失（原型污染类问题，与转义无关，尚未处理）。

## Joyous 插件：/mc 命令做成 AI 工具

- 文件：`extensions/handler/joyous/index.js`、`src/handler/ai.js`。
- 把 `/mc`（查服务器在线状态）的查询逻辑抽成共享 `fetchStatus(address)`（返回 `{ok,data|reason}` 判别结果）+ `renderStatus(result,name)`，命令与新增 AI 工具 `joyous:serverStatus` 共用，输出完全一致。
- 移除第二个坏掉的 `registerCommand('joyous','mc',...)`（同名冲突导致从不注册，且引用了未定义变量 `tool`），并清理随之失效的 `findTool`、`valToString` 导入。
- 修复 `ai.js` 的 `findTool` bug：`fqn.map(_toolFqn.get)` 丢失 `this` 绑定，改为 `fqn.map((name)=>_toolFqn.get(name))`（此前 `ai tool test` 命令因此一直报错）。
- 验证：端到端导入真实模块，命令/AI 工具在线、离线、非法 JSON 三场景输出正确且一致。
