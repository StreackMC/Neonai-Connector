## 语义定案：br = 强制分段（未提交）

用户明确：**Br 的语义是「强制分段」**，段内换行是「部分支持的特性」，需要时手写 `new TextFrag('\n')`。
所以上一轮那个 `static BLOCK = true` 的方向是对的，只需把边界收拾干净。

### 改动
- `toMarkdown()` 末尾裁掉首尾换行：`out.replace(/^\n+/,'').replace(/\n+$/,'')`。
  否则 `[br, 'a']` → `\n\na`、`['a', br]` → `a\n\n\n`。只有首尾被裁，代码块内部内容不受影响。
- `NeonaicBrMsgFrag`：`markdown` 从 `'\n'` 改为 `'\n\n'`（分段的本质就是空行本身）。
  这样即使不走 `toMarkdown()`、直接读 `frag.markdown` 的下游（qqbot）拿到的也是段落而不是单次换行。
  顺手删掉与 `static BLOCK` 重复的 `get isBlock()`，并修掉那句复制粘贴错的注释（曾写成「代码块是块级内容」）。
- qqbot `case 'br'` 改为 `qbSegment.markdown(frag.markdown)`，不再硬编码 `'\n'`。

### 定案后的行为
```
a + br + b            → "a\n\nb"   强制分段
a + TextFrag('\n') + b → "a\nb"     段内换行（软换行）
a + 2br + b           → "a\n\nb"    与 1 个等价（幂等）
[br, a, br]           → "a"         首尾被裁
[br]                  → ""          空消息
```
预期副作用：列表项里放 br ⇒ 该项分两段、整个列表变松散；引用块里同理。

38 → 50 项全绿。新增：单个 br 就分段、br 幂等、首尾裁掉、软换行走 TextFrag、
列表项内 br 变松散；并把 `[42]` 的断言改成适配 `NeonaicMessage` 新的「非法类型强转 String」契约。

## BUG 修复：TextFrag 套样式时未处理首尾空白

用户报：`**  aaa**`、`**\naaa**` 这类语法错误。根因是 `NeonaicTextMsgFrag.markdown`
直接 `**${text}**`，而 CommonMark 的强调要求**定界符紧贴非空白字符**：左侧 `**` 后面
一有空白就不是 left-flanking，整对标记退化成字面量。

用 markdown-it 实测（修复前）：
```
"**  aaa**"   → <p>**  aaa**</p>        星号原样
"**\naaa**"   → <p>** aaa**</p>         同上
"**aaa  **"   → <p>**aaa  **</p>        右侧空白同理
"* aaa*"      → <ul><li>aaa*</li></ul>  ← 比"不生效"更糟：变成列表项
"~~ aaa~~"    → <p>~~ aaa~~</p>
```

修复：新增 `styleText(raw, style)`——先 `^(\s*)([\s\S]*?)(\s*)$` 把首尾空白摘出来，
套完颜色/粗/斜/下划线/删除线再接回去；`core` 为空（纯空白/空串/单换行）时原样返回，
不产出空标记。

顺带处理了同类问题：**强调不能跨空行**。`'a\n\nb'` + bold 原本得到 `**a\n\nb**`，
同样不解析；现在按 `/(\n{2,})/` 切段、每段各自闭合 → `**a**\n\n**b**`。

修复后实测（markdown-it，`html: true`）：
```
"  **aaa**"    → <p><strong>aaa</strong></p>
"\n**aaa**"    → <p><strong>aaa</strong></p>
"**aaa**  "    → <p><strong>aaa</strong></p>
" *aaa*"       → <p><em>aaa</em></p>
" ~~aaa~~"     → <p><s>aaa</s></p>
"**a**\n\n**b**" → <p><strong>a</strong></p> <p><strong>b</strong></p>
```

确认下游未受影响：行内代码（含空格/换行/全空白）、链接 label 里的粗体、
标题里的斜体、无样式的文本（逐字不变）。

自检 50 → 58 项全绿（新增 C2 组 8 项：首/尾/两侧空白、斜体/删除线/下划线、
纯空白与空串、无样式逐字不变、多段分别闭合、多段删除线、定界符内侧无空白）。
