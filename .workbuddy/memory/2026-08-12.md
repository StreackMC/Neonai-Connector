## ai.js 工具调用不生效根因 + 修复（关键！）
- **现象**：`ai profile test deepseek 现在天气如何` 只返回 30 字角色扮演文本（如「喵呜~ 澪奈这就去看看外面的天气」），不调 `joyous_worldMeta` 工具，控制台无 tool_call 信息。
- **根因 1（核心代码 bug）**：`callProvider` 调 `generateText/streamText` 时**没设 `stopWhen`**，SDK 默认 `isStepCount(1)`（`node_modules/ai/dist/index.js:5240` 写死 `stopWhen = isStepCount(1)`）。结果：模型即便返回 tool_call，执行后立刻停止，`result.text` 为空，工具结果无法回读生成最终回答；且很多情况下模型会直接退化成角色扮演文本。
- **根因 2（可见性缺失）**：原 `callProvider` 只打 `← X 字符`，不输出任何 `toolCalls/toolResults`，无从判断 AI 是否调了工具。
- **对照实验**：用真实 deepseek + `stopWhen: stepCountIs(5)` 跑同一问题，模型**确实调用** `joyous_worldMeta`，拿到真实天气并合成 153 字正确回答 → 证明模型本身支持、问题纯在代码默认步数。
- **修复**（`src/handler/ai.js`）：
  1. import 增加 `stepCountIs`；`common` 加 `stopWhen: stepCountIs(5)` 打通「调用→取数→作答」闭环。
  2. 结果处理新增工具调用可见日志：`◉ <provider> 调用工具: <tool>(<args>)` 与 `↳ <tool> → <output>`（截断 200 字）。
  3. 修正流式隐患：`reply = (await result.text) ?? ''`，并对 `result.toolCalls/toolResults` 统一 `await`（streamText 模式下它们是 Promise；generateText 下是数组，await 兼容）。
- **验证**：语法检查通过；端到端经真实 `askAI('现在天气如何',['deepseek'])` 复现日志「◉ 调用工具: joyous_worldMeta(...)」并生成含真实天气的 153 字回答。
