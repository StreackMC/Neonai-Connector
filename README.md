# 澪奈 Neonai

> 与澪奈沟通的桥梁

一个基于 Node.js 的服务端项目，作为与澪奈（Neonai）沟通的桥梁。

## 功能特性

- **分模块配置**：`src/conf.js` 以声明式方式定义各模块内部名与配置路径的映射
- **分模块日志**：`src/logger.js` 以声明式方式定义日志类型，支持控制台 / 文件双输出与自动轮转
- **WebSocket 服务**：`src/websocket.js` 提供与客户端的连接能力
- **解耦合设计**：子模块之间通过组合根（`main.js`）依赖注入连接，互不直接引用

## 目录结构

```
Neonai/
├── main.js            # 入口（组合根，组装各子模块）
├── src/
│   ├── conf.js        # 配置模块
│   ├── logger.js      # 分模块日志
│   └── websocket.js   # WebSocket 服务
├── config/
│   ├── main.json      # 主配置
│   ├── websocket.json # WebSocket 配置
│   └── logger.json    # 日志配置
└── logs/              # 日志输出目录（运行时生成）
```

## 快速开始

```bash
npm install
npm start
```

## 配置

各模块的配置文件位于 `config/` 目录，内部名与配置路径的对应关系在 `src/conf.js` 中声明，新增模块只需在映射表中登记即可。

配置文件支持 **JSONC / JSON5** 语法（`src/conf.js` 使用 JSON5 解析）：可以写注释、保留尾逗号，也支持单引号字符串、无引号键名等 JSON5 特性，同时向后兼容严格 JSON。
